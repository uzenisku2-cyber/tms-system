# Sprint 146: přehled a rozhodnutí o zápočtech

Pracovní obrazovka „Zápočty PHM a vozidla“ je dostupná dopravci a zaměstnanému řidiči. Zobrazuje jen vlastní sdílené položky, částku, období a stav rozhodnutí. Každé přijetí či odmítnutí vyžaduje důvod. Po uložení se seznam obnoví. Server vždy znovu ověřuje totožnost protistrany, aktuální verzi položky i její stav.
