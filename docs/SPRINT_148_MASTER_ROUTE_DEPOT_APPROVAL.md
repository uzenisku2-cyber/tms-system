# S148 – Schvalování shody v přehledu tras

Nadřazená organizace čte aktuální provozní porovnání vlastních tras se zápisem depa přímo v záložce Trasy. Jen shodná dosud neschválená trasa nabízí potvrzení přes stávající auditované API; server znovu ověřuje verzi výkazu, jednoznačný zdroj depa a provozní shodu. Podřízený dopravce a řidič stále čtou jen své trasy. Schválení samo nevystavuje fakturu, neproplácí ani nezaúčtovává.
