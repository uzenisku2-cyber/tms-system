# Sprint 126: Customer invoice PDF artifact

An authenticated issuer or customer may download an approved or closed customer invoice as PDF. The first download renders a text-only A4 document from the immutable issuance snapshot with a bundled Unicode font and stores it on the private local disk. A single organization-scoped artifact row records the commercial identity, snapshot digest, PDF SHA-256, byte count, generation time and actor. Later downloads return those stored bytes after integrity checks; a missing, altered or mismatched artifact returns a conflict rather than silently regenerating it. Drafts are rejected. The Finance workspace offers a separate PDF download button alongside the browser print view. No email delivery, external file service or payment reconciliation is added. The application requires `dompdf/dompdf` pinned by `composer.lock`.
