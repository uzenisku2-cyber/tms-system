# Sprint 142 – průběžná odměna dopravce

Stránka Průběžná odměna čte omezené API dopravce a zobrazuje orientační částky po měsících a trasách. Částky vycházejí z aktuálních zápisů řidičů a historických ceníků. Zvlášť uvádí samostatný příplatek trasy. Neúplné nebo neoceněné výkazy brání zobrazení celkové částky; při neúplném měsíci čeká příplatek za kvalitu na doplnění. Stránka neumožňuje fakturaci ani zápis finančních výpočtů. K fakturaci je nutná shoda se zápisem depa.
