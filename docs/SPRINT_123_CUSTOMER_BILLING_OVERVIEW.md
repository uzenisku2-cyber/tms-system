# Sprint 123: Customer billing overview and invoice workflow

## Overview navigation

The existing organization-scoped billing overview now validates a document status filter and page number. The Finance panel displays 25 documents per page with previous and next controls and resets to page 1 when filters change. The company summary still covers every document matching the filters, including documents on other pages. Authorization and own-view restrictions remain server-owned.

## Next workflow unit

The customer invoice creation workflow will use final financial calculations, verified customer relationships, explicit commercial identity, tax profile, source snapshots, exact monetary totals and duplicate-source protection. A draft is not presented as an issued invoice. Payment, settlement, and accounting posting remain separate actions.
